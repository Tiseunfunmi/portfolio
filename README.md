## 📌 About

This portfolio highlights projects I've built while learning web development and app design.

## ✨ Features

- Responsive hero section with smooth scroll navigation
- Project showcase cards with links to live demos
- Contact form with client-side validation, powered by Netlify Forms (no backend required)
- Clean, dark-themed UI designed in Figma

## 🛠️ Tech Stack

- **HTML5** — page structure
- **CSS3** — styling and layout (Flexbox & Grid)
- **JavaScript** — form validation
- **Netlify Forms** — contact form submission handling
- **Figma** — UI/UX design

## 🚀 Getting Started

1. Clone the repository:
   ```
   git clone https://github.com/Tiseunfunmi/portfolio.git
   ```
2. Open `index.html` in your browser — no build tools required.

## 🌐 Deployment

This project is deployed via **Netlify**, connected directly to this GitHub repository for continuous deployment. Every push to `main` automatically triggers a redeploy.

Contact form submissions are captured through **Netlify Forms** and viewable in the Netlify dashboard under the site's **Forms** tab.
